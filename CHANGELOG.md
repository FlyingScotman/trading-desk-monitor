# Что нового в Desk Monitor

Версия программы — `backend/pyproject.toml`; релиз на GitHub — тег `v<версия>`. Раздел версии отсюда попадает
в описание релиза (`backend/tools/release_assets.py`).

## 0.2.1

Промежуточный выпуск, 22.10.2026. Ставится поверх 0.2.0: настройки, токен, данные и адаптер сохраняются.

**Сначала проверьте обновление программы.** С этой версии программа сама узнаёт о новых версиях на GitHub.
Настройки → «Обновление программы» → блок «Новая версия с GitHub»:

1. «Связь с GitHub и настройки обновления» → **«Диагностика связи»**: какая строка зелёная. Есть зелёный способ
   сервера (Python, curl или PowerShell) — следующие версии будут скачиваться без браузера. Зелёная только строка
   «Браузер» — через папку «Загрузки». Красные строки — под таблицей написано, что сказать ИТ.
2. **«Проверить сейчас»**: блок должен показать, что установлена последняя версия (или «релизов пока нет»).
3. Само обновление кнопкой «Обновить до …» заработает со следующего выпуска. Откат — кнопка «Вернуть …».

Адаптер в архив с GitHub не входит никогда: при обновлении установленный `adapter\` остаётся как есть.

**Мониторы — основной интерфейс**
- В меню, на главной и на странице мониторов остались мониторы C01–C13, точные сценарии и настройки. Прежние
  экраны (Desk Monitor, Widget Board, Pivot Studio, Scenario & PnL Lab) из меню убраны, но открываются по прямой
  ссылке. start.bat после настройки открывает мониторы.

**Риски**
- Кокпит (C01): новая вкладка **«Валюта × тип»** — по каждой валюте итог и разбивка по группам и типам
  инструментов (ОФЗ-ПД/ПК/ИН, валютные суверенные, субфедеральные, корпоративные фикс/флоатер, IRS, CCS, фьючерсы,
  форварды и т. д.): номинал, MV, DV01 по своим кривым и по кривым, базис ОФЗ, CS01, FX-дельта и число позиций
  без риска (с причиной, не 0). Любая цифра раскрывается до позиций. Валюта кросс-валютных сделок (CCS, форварды,
  валютные фьючерсы) — по ногам или по валюте позиции, переключатель.
- **FX-дельта по каждой валюте** (форвард USD/CNY даёт дельту и в USD, и в CNY, а не одну сумму), **DV01 по валюте
  кривой**. Шапка (DV01, ОВП), плитки и таблицы по валютам считают одинаково на всех страницах.
- **Блоки валют в кокпите строятся по данным прогона**: появляется любая валюта и кривая, по которой есть риск
  (неявная кривая CNY, CHF и т. д.), без заранее заданного списка.
- Карточка позиции: FX-дельта по валютам, DV01 по кривым и по валютам кривых, таблица ног сделки (даты, суммы,
  курс сделки и форвардный курс).

**Мониторы, батч 1**
- **Подсказки** у DV01, Базис01 и CS01 (заголовки таблиц, KPI кокпита, матрица рисков, карточка): что именно
  сдвигается на 1 б.п. Почему базис ОФЗ меньше DV01 RUONIA на 13–14 %: Базис01 = DV01 / (1 + R).
- **Сортировка групп**: щелчок по заголовку сортирует и группы на всех уровнях (по сумме группы, где есть итог).
- **Карточка позиции**: риск по кривым у каждой позиции (и у облигаций), таблица «кривая × срок», спред:
  у фикс-бумаг Z-спред к RUONIA, у флоатеров DM и Z к RUONIA; в C03 — колонка «Z к RUONIA».
- **Своё название бумаги**: в карточке позиции и в C03 значок ✎ — название меняется прямо в карточке (Enter —
  сохранить, Esc — отмена, «Биржевое имя» — вернуть), ⟲ — история изменений. Биржевое имя видно в подсказке,
  поиск ищет по обоим. Менять можно только на самой рабочей машине (http://127.0.0.1:8100); с других
  компьютеров название только показывается.

**Под капотом (в расчётах ещё не участвует)**
- **Приватный контракт 1.2**: программа принимает и хранит новые наборы адаптера — ОВП, остатки кэша, официальный
  PnL, условия сделок (FX-форварды, NDF, свопы), книги FUTURES, справочники юрлиц и правил фондирования, вкладки
  настроек адаптера. В прогонах и на страницах они пока не используются.
- **Движок фондирования** (по правилам из адаптера) готов и проверен тестами, но в прогоны не включён:
  фондирование во флэш-PnL пока 0.

**Совместимость**
- **Адаптер 0.3.0** (контракт `private/1.2`) работает только с этой версией программы или новее: старая программа
  его не загрузит (`bad_source`). Поэтому сначала программа 0.2.1, потом адаптер.
- Прежние адаптеры (контракт 1.1) с 0.2.1 работают как раньше.
- База данных дополняется двумя таблицами при первом запуске; откат на 0.2.0 кнопкой «Вернуть …» возможен.
- Номер версии вырос, поэтому последний день пересчитается сам, прошлые прогоны — фоном.
