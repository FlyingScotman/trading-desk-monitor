# Установка и запуск на рабочей машине (Windows)

Монитор — это сайт, к которому подключаются браузеры коллег. Он работает на вашей машине (или на любом Windows-сервере) и не требует установки пакетов: нужен только Python 3.9+. Все зависимости — стандартная библиотека, поэтому `pip` и доступ в интернет не нужны.

## 1. Что понадобится

- Python 3.9 или новее. Проверить, есть ли он:

  ```bat
  python --version
  ```
  - `python` — интерпретатор Python;
  - `--version` — флаг: напечатать версию и выйти.

  Если команда не найдена, попробуйте `py -3 --version`:
  - `py` — стандартный Windows-лаунчер Python;
  - `-3` — выбрать установленный Python 3.

  Если нет ни того ни другого, поставьте Python с python.org или через корпоративный портал ПО. Пункт «Add python.exe to PATH» в установщике сделает команду `python` доступной.

- Папка для монитора, например `C:\tdm`. Лучше на локальном диске, не на сетевой шаре: база SQLite на сетевых дисках работает ненадёжно.

## 2. Получить код

**Вариант А — git (если есть):**

```bat
git clone -b claude/clever-ramanujan-s4k3ed https://github.com/FlyingScotman/trading_desk_monitor.git C:\tdm
```

- `git clone` — скачать репозиторий целиком;
- `-b claude/clever-ramanujan-s4k3ed` — сразу переключиться на эту ветку (после слияния в `main` флаг можно не указывать);
- `https://github.com/...git` — адрес репозитория;
- `C:\tdm` — папка, куда положить код.

**Вариант Б — архив:** на GitHub откройте ветку → **Code → Download ZIP**, распакуйте в `C:\tdm`.

## 3. Первичная настройка

```bat
cd /d C:\tdm
install.bat
```

- `cd` — перейти в папку; `/d` — сменить заодно и диск (если вы были, например, на `D:`);
- `install.bat` — скрипт первичной настройки. Он:
  1. проверяет, что Python не старше 3.9;
  2. создаёт пустую базу `C:\tdm\data\tdm.sqlite`;
  3. прогоняет тесты (около секунды);
  4. спрашивает, загрузить ли демо-прогон. Ответьте `y`, чтобы сразу увидеть страницы на данных из базы.

## 4. Запуск сайта

```bat
run.bat
```

- `run.bat` запускает веб-сервер на порту 8080 и слушает все сетевые интерфейсы, чтобы коллеги могли подключиться. Остановить — `Ctrl+C` в окне.
- `run.bat 9000` — то же на порту 9000 (первый аргумент — номер порта).

Внутри `run.bat` выполняется:

```bat
python -m tdm --db "C:\tdm\data\tdm.sqlite" serve --host 0.0.0.0 --port 8080
```

- `python -m tdm` — запустить пакет `tdm` как программу (`-m` = «модуль»);
- `--db "…"` — файл базы. Без флага берётся переменная окружения `TDM_DB`, а если её нет — `data\tdm.sqlite` в текущей папке;
- `serve` — команда «запустить веб-сервер»;
- `--host 0.0.0.0` — принимать подключения со всех сетевых адресов машины. Значение `127.0.0.1` пустит только вас;
- `--port 8080` — номер порта.

Откройте в браузере `http://localhost:8080/`.

Коллеги заходят по `http://<имя-или-IP-вашей-машины>:8080/`. Узнать IP:

```bat
ipconfig
```

`ipconfig` показывает сетевые настройки; нужна строка «IPv4-адрес» активного адаптера.

## 5. Открыть порт в брандмауэре (чтобы зашли коллеги)

Выполнить один раз, **в командной строке от имени администратора**:

```bat
netsh advfirewall firewall add rule name="Trading Desk Monitor" dir=in action=allow protocol=TCP localport=8080 profile=domain
```

- `netsh advfirewall firewall add rule` — добавить правило брандмауэра Windows;
- `name="…"` — имя правила, по нему его потом можно найти и удалить;
- `dir=in` — для входящих подключений;
- `action=allow` — разрешить;
- `protocol=TCP localport=8080` — только TCP-порт 8080;
- `profile=domain` — только в корпоративной (доменной) сети, не в публичных Wi-Fi.

Если прав администратора нет, отправьте эту команду в ИТ. Если корпоративная политика запрещает слушать порты на рабочих станциях, монитор ставится так же на любой Windows-сервер: `run.bat` и база переносятся копированием папки.

Удалить правило:

```bat
netsh advfirewall firewall delete rule name="Trading Desk Monitor"
```

## 6. Автозапуск (чтобы сайт работал без открытого окна)

**Планировщик заданий** — встроен в Windows, отдельно ставить ничего не нужно:

```bat
schtasks /create /tn "Trading Desk Monitor" /tr "C:\tdm\run.bat" /sc onlogon /rl limited /f
```

- `schtasks /create` — создать задание;
- `/tn "…"` — имя задания;
- `/tr "C:\tdm\run.bat"` — что запускать;
- `/sc onlogon` — при входе пользователя в систему (на сервере можно `/sc onstart` — при загрузке ОС, но тогда нужны права администратора и учётная запись задания `/ru`);
- `/rl limited` — с обычными правами, без повышения;
- `/f` — перезаписать задание, если оно уже есть.

Запустить сразу, не дожидаясь входа: `schtasks /run /tn "Trading Desk Monitor"`. Удалить: `schtasks /delete /tn "Trading Desk Monitor" /f`.

## 7. Подключение расчётного сервиса

Расчётный сервис пишет в **тот же файл** `C:\tdm\data\tdm.sqlite`. Подробно — `docs/DATA_CONTRACT.md`.

**Python (рекомендуется).** В коде расчётного сервиса:

```python
import sys; sys.path.insert(0, r"C:\tdm")   # сделать пакет tdm видимым
from tdm.writer import Run
```

Или установить пакет в окружение расчётного сервиса без интернета:

```bat
pip install --no-build-isolation C:\tdm
```

- `pip install` — установить пакет;
- `--no-build-isolation` — собирать пакет уже установленным `setuptools`, не скачивая его из интернета;
- `C:\tdm` — путь к папке с `pyproject.toml`.

Шаблон: `python examples\calc_service_stub.py --db C:\tdm\data\tdm.sqlite --as-of 2026-10-13`
- `--db` — файл базы;
- `--as-of` — дата среза.

**Любой другой язык.** Сформируйте JSON-пакет (`contract/bundle.schema.json`) и загрузите его:

```bat
python -m tdm --db C:\tdm\data\tdm.sqlite import C:\exchange\run_2026-10-13.json
```

`import` — загрузить один или несколько файлов. Код возврата 0 — прогон опубликован, 1 — ошибка (текст на экране и на стартовой странице сайта).

## 8. Полезные команды

| Команда | Что делает |
|---|---|
| `python -m tdm load C:\tdm_data\` | загрузить входные данные из CSV: все `*.csv` в папке и подпапках; набор определяется по имени файла (`docs/DATA_REQUIREMENTS.md`) |
| `python -m tdm coverage --from 2025-10-13` | таблица «дата × набор данных»: сколько строк загружено, есть ли EOD-прогон; `--from`/`--to` — период |
| `python -m tdm build-hist-scenarios --horizon 1 10 --top 5` | исторические сценарии: `--horizon` — окна в рабочих днях, `--top` — сколько худших окон каждой длины |
| `daily.bat` | ежедневная загрузка: всё из папки `inbox\` → база, файлы переносятся в `inbox\done\`, затем пересборка исторических сценариев |
| `python -m tdm runs` | последние 20 прогонов: дата, тип, статус, ошибка. `--limit 50` — показать 50 |
| `python -m tdm demo` | загрузить демо-прогон из `fixtures\demo_bundle.json` |
| `python -m tdm init-db` | создать пустую базу (если её нет) |
| `python -m tdm purge --keep-days 90 --keep-eod` | удалить прогоны старше 90 последних дат; `--keep-eod` — по старым датам оставить последний EOD |
| `python -m unittest discover -s tests` | прогнать тесты: `-m unittest` — встроенный тест-раннер; `discover -s tests` — найти тесты в папке `tests` |

Ко всем командам `tdm` можно добавить `--db <файл>` (до имени команды), если база лежит не в `data\tdm.sqlite`.

## 9. Бэкап

Скопируйте папку `C:\tdm\data` при остановленном сервере. Пока сервер работает, используйте `sqlite3 data\tdm.sqlite ".backup D:\backup\tdm.sqlite"` (утилита `sqlite3.exe` с sqlite.org). `.backup` делает согласованную копию на ходу.

## 10. Если что-то не так

| Симптом | Причина / что делать |
|---|---|
| На страницах жёлтая плашка «ДЕМО-данные» | в базе нет опубликованных прогонов; проверьте `python -m tdm runs` и колонку «Ошибка» на стартовой странице |
| Коллеги не открывают сайт, а у вас открывается | брандмауэр (раздел 5) или сервер запущен с `--host 127.0.0.1` |
| `Address already in use` / `OSError: [WinError 10048]` | порт занят: `run.bat 8081` |
| Шрифты выглядят иначе, чем на скриншотах | у машины нет доступа к Google Fonts; используются системные шрифты, на работу это не влияет |
| Кракозябры в консоли | `run.bat` сам переключает консоль в UTF-8 (`chcp 65001`); при ручном запуске сделайте то же |
