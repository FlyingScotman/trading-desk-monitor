# Trading Desk Monitor decision register

Revision 0.2, 22 October 2026 (revision 0.1: 14 October 2026). Open decisions are not implicit approvals. An implementing agent can build fixtures and measure alternatives while a financial decision is pending, but cannot release the affected behavior. Do not repeatedly ask the owner to accept ordinary reversible implementation details already covered by the specification.

**This file is canonical for the generic decision IDs DEC01–DEC12 and the open questions OQ-NN below.** The organization's own answers (values, rates, which option the organization uses) are firm-specific and live in the private adapter `trades-data-adapter` ([ADR-008](../architecture/adr/ADR-008-private-adapter-boundary.md)): `docs/ORG_RULES.md` §9 (questions Q-F*, Q-S*, Q-P*) and the historical `docs/ORG_CONVENTIONS.md` §8 (TBD 1–10). Those documents should cite the DEC ID they answer instead of restating the decision; the column "Private cross-references" below is the mapping. A private question with no DEC ID is a question about the organization's data or values only (which report, which rate), not a generic decision.

## Established constraints

Positions, private trade terms, internal PnL, cash balances, funding settings and portfolio results remain inside the organization. Local Python and public-data downloads are available on the work PC. VPS reachability and corporate proxy behavior require a real connection test.

The external server collects and serves market and static data (`market-data-hub`). The financial library is `rub-fixed-income-core`, pinned by the backend. Code generation and development take place outside work using public/synthetic inputs. (Revision 0.1 expected the library from the Hermes VPS and a runtime agent there; both are superseded by ADR-001 and the existing repositories.)

No password, token or private data belongs in this register. These inputs gate only dependent work.

## Change procedure

For each decision record status, owner, date, rationale, affected requirement IDs, chosen rule, alternatives rejected, test evidence and required contract version. Put approved changes in a reviewed PR. A coding agent does not promote a financial assumption into a confirmed convention by implementing it.
