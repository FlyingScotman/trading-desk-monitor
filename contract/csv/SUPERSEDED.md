# Contract 1.3 templates superseded for the backend

The CSV templates in this folder are contract 1.3 of the prototype `tdm` (generated by `tools/gen_data_docs.py`
from `tdm/datasets.py`, described in `docs/DATA_REQUIREMENTS.md`). They stay as they are for the prototype. The
backend (`backend/`, `desk`) reads the desk's own data through the private adapter instead, in the private input
contract v1 ([`contract/private/v1/`](../private/v1/README.md), [08 §10](../../docs/architecture/08_PRIVATE_ADAPTER_INTERFACE.md)).
Where both describe the same thing, the private contract is the one to build against:

| 1.3 template | Superseded by (private contract v1) |
|---|---|
| `positions.csv` | `positions` |
| `books.csv` | `reference()["books"]` (`book_type` `TRADING`, `HTM`, `DERIVS`, `FUTURES`) |
| `funding_rates.csv` | `reference()["funding_rules"]` |
| `cash_balances.csv` | `cash_balances` |
| `pnl_official.csv` | `pnl_official` |
| `otc_deals.csv` | `trade_terms` (FX forwards, NDFs, FX swaps since 1.2; swaps, CCS, CDS later) and `positions` (`otc` rows) |
| `funding.csv` | `trade_terms` (REPO: a later minor) |
| `trades.csv` | `trades` |

Market data (`md_*.csv`), static data (`instruments.csv`, `issuers.csv`, `bond_cashflows.csv`, ...) and calendars
come from the market data hub for the backend, not from these templates.
