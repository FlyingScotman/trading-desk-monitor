Автообновление

Сервер сам загружает срезы с маркет-дата сервера, забирает новые отчёты из папок и пересчитывает риски.

В рабочие дни с 10:00 МСК портфель дня пересчитывается на свежем внутридневном срезе маркет-дата сервера (не чаще раза в 30 минут), после 19:45 — на предварительном закрытии; PnL — к закрытию предыдущего рабочего дня. Утром его заменяет расчёт на окончательном закрытии. Хранится только последний внутридневной расчёт дня.

Пусто — 35. Возраст считается по дате отчёта (из имени или содержимого файла), а не по дате изменения файла: книга, по которой отчёт приходит раз в несколько недель, тоже загрузится. Более старые отчёты не читаются (папку с архивом за годы можно оставить, она просматривается один раз), снимки с маркет-дата сервера за более ранние даты не загружаются. 0 — без ограничения (медленно на больших папках).

Изменения применяются со следующего цикла (не позже чем через период опроса), перезапуск сервера не нужен.

Пусто — 260 (около года). Для графиков цен и доходностей сервер понемногу, по нескольку дат за цикл, догружает с маркет-дата сервера котировки за прошлые дни. 0 — не догружать, только загруженные срезы. Если сервер отдаёт API истории (версия 0.2.0 и токен с правом read), история берётся оттуда — на годы назад, вместе с КБД, кривыми, фиксингами и курсами, а это число не действует (кроме 0 — выключено).

Пусто — 2024-01-03 (с этой даты у сервера есть закрытия облигаций). Только для API истории.

КБД, кривые RUONIA OIS и КС-свопов, фиксинги (КС, RUONIA, RUSFAR, ИПЦ), курсы ЦБ и MOEX. Пусто — 2010-01-01 (или сколько есть на сервере).

Сервер в фоне считает прошлые даты: по каждой рабочей дате с позициями (отчёт дня, а без него — последний предыдущий отчёт книги) — расчёт на окончательном закрытии этой даты. Из них — история риска, MV, PnL с начала месяца и года. Сначала один раз читает старые отчёты из папок (старше окна выше), потом считает даты от самой ранней, в конце каждого цикла и не дольше заданного времени, так что текущий день не ждёт. Уже посчитанные даты с теми же входными данными не пересчитываются. Ход — в разделе «История прогонов» ниже; то же сразу целиком: desk.bat backfill.

Пусто — 05.01.2026, первое окончательное закрытие на маркет-дата сервере.

Пусто — 600. Одна дата всегда досчитывается до конца, даже если время вышло.

Доступ по сети

Выключено — страницы открываются только на этом компьютере. Включено — сервер принимает подключения из сети, и коллеги открывают Desk Monitor по имени или адресу этого компьютера (ниже). Настройки, обновление программы и диагностика по-прежнему открываются только здесь. Входа по паролю нет: позиции и риски увидит любой, кто откроет адрес из сети.

Применяется после перезапуска сервера: закройте окно Desk Monitor и снова запустите start.bat. Если Windows спросит, разрешить ли Python доступ к сети, — разрешите. Если коллеги всё равно не открывают страницу — порт закрыт брандмауэром: INSTALL_BACKEND_WINDOWS.md, раздел «Доступ коллег по сети».

Диагностика

Без позиций, книг, ISIN и сумм — можно передать агенту. Файл описывает работу программы: версию, настройки (без путей и паролей), шаги автообновления, срезы рынка и наличие кривых, счётчики отчётов и прогонов, ошибки журналов по видам.
