Маркет-дата сервер

токен …

Только https:// (http — лишь для 127.0.0.1).

Токен хранится отдельно в файле hub_token и никогда не показывается.

Пароль хранится отдельно в файле proxy_password и никогда не показывается.

Если прокси пускает по учётке Windows, логин/пароль не нужны: способ "curl Windows" использует текущего пользователя. «Авто» сам переходит на curl, если прокси требует вход.

Нужен, только если корпоративный прокси подменяет сертификаты и система их не знает.

Автообновление

Сервер сам загружает срезы с маркет-дата сервера, забирает новые отчёты из папок и пересчитывает риски.

Пусто — 10. Более старые файлы в папках с отчётами не читаются (папку с архивом за годы можно оставить), снимки с маркет-дата сервера за более ранние даты не загружаются. 0 — без ограничения (медленно на больших папках).

Изменения применяются со следующего цикла (не позже чем через период опроса), перезапуск сервера не нужен.
