Концепты интерфейса монитора деска

Несколько разных ответов на вопрос «как должен выглядеть монитор». Это не варианты одного экрана, а разные подходы: кокпит со вкладками, экран целиком про риск, таблица позиций в центре, агрегатор с пресетами, утренний брифинг, плиточная доска, командная строка, визуальная карта, рынок, календарь, эмитенты. Отметьте, что нравится, и напишите, что взять: следующая итерация соберёт целевой интерфейс из отмеченного.

Работает везде

  • Щелчок по любой сумме (пунктир) раскрывает, из каких позиций она складывается; разрез по эмитентам, книгам, валютам, типам, срокам; таблица или график.
  • Щелчок по позиции открывает карточку: параметры, PnL по факторам, история цены, доходности, спреда и номинала, риск по бакетам, потоки.
  • Поиск по всему: Ctrl K или /.
  • Сортировка по нескольким колонкам: Shift+щелчок по заголовку.
  • Фильтр книг в шапке общий для всех концептов.
