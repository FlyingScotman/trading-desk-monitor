Мониторы деска

Работает везде

  • Щелчок по любой сумме (пунктир) раскрывает, из каких позиций она складывается; разрез по эмитентам, книгам, валютам, типам, срокам; таблица или график.
  • Щелчок по позиции открывает карточку: параметры, PnL по факторам, история цены, доходности, спреда и номинала, риск по бакетам, потоки.
  • Поиск по всему: Ctrl K или /.
  • Сортировка по нескольким колонкам: Shift+щелчок по заголовку.
  • Фильтр книг и портфелей в шапке общий для всех мониторов.

Данные вымышленные (prototypes/concepts/lib/mock.js), расчёты упрощённые.
