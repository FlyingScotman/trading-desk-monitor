Desk Monitor - установка на рабочий компьютер (Windows 10/11, 64 бит)

Python, встроенная база и сама программа лежат в этой папке, права администратора не нужны.
Сторонние Python-библиотеки в архиве не лежат: при первом запуске start.bat ставит их с зеркала
pip этого компьютера (раздел «КОМПЛЕКТ БЕЗ ПАКЕТОВ» ниже), нужен доступ к нему. Это единственный
вид, который теперь выпускается; если у вас стоит прежний полный комплект, см. «ПЕРЕХОД» ниже.

1. РАСПАКОВАТЬ
   - Если архив пришёл по почте или из интернета: правой кнопкой по zip -> Свойства ->
     галочка «Разблокировать» -> ОК. Иначе Windows будет спрашивать про каждый запуск.
   - Распакуйте архив в свою папку на локальном диске с путём БЕЗ пробелов и русских букв,
     например C:\DeskMonitor (иначе start.bat попросит перенести папку: встроенный PostgreSQL
     с такими путями не работает). Не в Program Files и не на сетевой диск.
   - Проводник создаёт вложенную папку - это нормально: рабочая папка та, где лежит start.bat.

2. ЗАПУСТИТЬ: двойной щелчок по start.bat.
   Первый запуск ставит окружение (1-5 минут) и создаёт базу, затем открывает браузер.
   Окно start.bat не закрывайте: пока оно открыто, Desk Monitor работает.
   Закрыть окно (или stop.bat) = остановить.

3. НАСТРОИТЬ. При первом запуске откроется страница настроек
   (потом: http://127.0.0.1:8100/settings.html или ссылка «Настройки» на странице мониторов):
   - адрес хаба и токен, кнопка проверки связи;
   - папки, куда приходят отчёты;
   - файлы настроек адаптера.
   Дальше автопилот сам забирает снапшоты с хаба, подхватывает новые отчёты и считает EOD.
   Мониторы: http://127.0.0.1:8100/concepts/index.html

ГДЕ ЧТО ЛЕЖИТ
   Программа - эта папка. Её можно удалить и заменить новой версией.
   Данные и настройки - %LOCALAPPDATA%\DeskMonitor: база, снапшоты, settings.json, токен,
   журналы (logs\serve.log). Они переживают обновления. Если в этом пути русские буквы
   (имя пользователя кириллицей) - C:\DeskMonitorData (start.bat пишет путь при запуске).
   Другое место для данных: в командной строке  setx DESK_HOME D:\DeskData  и перезапуск start.bat.

ОБНОВЛЕНИЕ
   С GitHub, одной кнопкой: программа сама находит новую версию («Новая версия ...» в шапке),
   Настройки -> «Обновление программы» -> «Обновить до ...». Архив скачивает сервер или, если
   сеть не пускает программы, браузер в папку «Загрузки»; программа сверяет SHA-256 с релизом,
   ставит и перезапускается. «Диагностика связи» там же показывает, какой путь работает.

   Из zip-файла, без остановки: Настройки -> «Обновление программы».
   1. Положите zip новой версии (полный DeskMonitorMirror-....zip или заплатку
      DeskMonitorMirror-patch-....zip) в папку обновлений - её путь задаётся там же, подойдёт
      сетевая папка, - или нажмите «Загрузить zip с компьютера».
   2. «Установить» у нужного архива. Программа проверит архив, перезапустится сама
      (около минуты; окно start.bat не закрывайте) и откроет страницу уже в новой версии.
      Если новая версия не запустится, вернётся прежняя, а на странице будет причина.
      Резервные копии заменённых файлов: %LOCALAPPDATA%\DeskMonitor\updates\backup.

   Вручную (в первый раз, пока установлена версия без этого раздела, или если страница
   так советует, например когда в архиве другой Python):
   1. Остановите старую версию: stop.bat в её папке (окно start.bat не закрывайте: база данных остановится аварийно).
   2. Распакуйте новую версию в любую папку (или поверх старой) и запустите её start.bat.
      Он сам переустановит окружение под новую версию; настройки и данные остаются.
   3. Старую папку (если она другая) можно удалить.

ФАЙЛЫ
   start.bat         запуск; при первом запуске и после обновления - установка
   stop.bat          остановить сервер и встроенную базу (PostgreSQL)
   update_daily.bat  один цикл автопилота сейчас (хаб, отчёты, EOD); можно в Планировщик заданий
   desk.bat          команды из командной строки (запасной путь): desk.bat config, desk.bat hub-check,
                     desk.bat user ..., desk.bat lan ... - то же есть на странице настроек
   app\INSTALL_BACKEND_WINDOWS.md  подробная инструкция и решение проблем

ЕСЛИ ЧТО-ТО НЕ ТАК
   Сообщение об ошибке остаётся в окне. Журнал сервера: %LOCALAPPDATA%\DeskMonitor\logs\serve.log.
   Порт занят, прокси, антивирус и прочее: app\INSTALL_BACKEND_WINDOWS.md, раздел «Если что-то не так».

ДОСТУП ИЗ СЕТИ (коллегам, по паролю) И ПЕРЕЗАПУСК
   По умолчанию Desk Monitor слушает только 127.0.0.1 (этот компьютер) и входа нет. Включается
   на странице настроек, без командной строки (по шагам - START_HERE.txt, раздел 9):
     Настройки -> «Пользователи»        себя - администратором, затем коллег (имя, роль, пароль)
     Настройки -> «Доступ из сети»      «Доступ коллегам», HTTPS, порт -> «Применить и перезапустить»
                                        (сервер перезапустится сам; не запустится - вернёт прежнее)
     там же «Брандмауэр Windows»        «Скопировать для ИТ» - текст заявки с командой: правило
                                        брандмауэра ставят с правами администратора Windows
     там же «Адреса для коллег»         что отправить коллегам, кнопка «Скопировать»
     там же «Перезапустить сервер»      перезапуск без stop.bat / start.bat (окно start.bat остаётся)
   Правило брандмауэра (его выполняет и desk.bat firewall add в cmd от имени администратора):
     netsh advfirewall firewall add rule name="Desk Monitor (TCP 8100)" dir=in action=allow protocol=TCP localport=8100 profile=domain,private
     (входящие, разрешить, только TCP-порт 8100, только сети домена и частные).
   Командная строка - запасной путь, делает то же (в этой папке):
     desk.bat user add ИМЯ --role admin      администратор (пароль спросят)
     desk.bat lan enable --self-signed       вход по паролю, сеть, HTTPS со своим сертификатом
     desk.bat lan disable                    снова только этот компьютер
     stop.bat, start.bat                     перезапуск; окно покажет адрес для коллег
   Сервер откажется слушать сеть без входа по паролю, и без HTTPS - если не задано явно HTTP.

КОМПЛЕКТ БЕЗ ПАКЕТОВ (архив DeskMonitorMirror-....zip; единственный выпускаемый вид)
   Сторонних Python-пакетов в архиве нет: при первом запуске start.bat ставит их (1-5 минут) с внутреннего
   индекса пакетов (зеркала pip) этого компьютера. Python, база, настройки и данные - как в прежнем
   полном комплекте (DeskMonitor-....zip, он больше не выпускается).
   Подробнее: app\INSTALL_BACKEND_WINDOWS.md, раздел 11.

ПЕРЕХОД С ПРЕЖНЕГО ПОЛНОГО КОМПЛЕКТА (один раз, вручную)
   «Обновление программы» не может сменить вид архива, поэтому на странице вместо кнопки будут эти шаги:
   1. Сначала скачайте DeskMonitorMirror-<версия>.zip: ссылка под шагами на странице «Обновление программы»
      или страница релиза на GitHub. После остановки программы страница перестанет открываться.
   2. Остановите программу: stop.bat в старой папке. Затем распакуйте скачанный архив в НОВУЮ пустую папку
      (не поверх старой).
   3. Если стоял приватный адаптер, перенесите папку adapter из старой папки в новую (Проводником или
      командой  xcopy C:\DeskMonitor\adapter C:\DeskMonitor2\adapter /E /I /Y  : xcopy - копирование папок,
      первый путь - откуда, второй - куда, /E - с вложенными папками, /I - создать папку назначения, если её
      нет, /Y - не спрашивать при замене файлов; пути подставьте свои).
   4. Запустите start.bat в новой папке.
   Данные и настройки лежат в папке данных (DESK_HOME), не в папке программы: переносить их не нужно.
   Старую папку можно удалить, когда убедитесь, что новая работает.

   Смотрит ли pip компьютера на зеркало. В папке программы, в командной строке:
       python\python.exe -m pip config list
     (python\python.exe - Python из комплекта; -m pip - запустить его модуль pip; config - подкоманда
      «настройки pip»; list - показать действующие значения).
     Должна быть строка с адресом зеркала: global.index-url='...', install.index-url='...' или
     :env:.index-url='...' (последняя - если адрес задан переменной среды PIP_INDEX_URL). Адрес может содержать логин и пароль:
     целиком его никому не пересылайте.

   Файл mirror.ini (необязателен). Читается первый найденный: сначала в папке программы (рядом с start.bat),
   затем %LOCALAPPDATA%\DeskMonitor\mirror.ini (или в папке из DESK_HOME). Пример (адреса вымышленные):
       [mirror]
       index_url = https://pip.example.invalid/simple
       extra_index_url = https://pip2.example.invalid/simple
       strict = false
     [mirror] - заголовок раздела; index_url - основной индекс (pip получает его явно, --index-url; не задан -
     работают настройки компьютера); extra_index_url - дополнительный индекс (--extra-index-url), по желанию;
     strict - true или false (по умолчанию false), строгий режим.

   Строгий режим: ставятся только версии, проверенные у нас, любое отличие - отказ. На один запуск:
       start.bat --strict-mirror
     (start.bat - запуск; --strict-mirror - ключ строгого режима, действует поверх mirror.ini).
     Постоянно - strict = true в mirror.ini.

   Порядок подбора версий, если нужной нет на зеркале (гибкий режим): версия из lock -> та же minor-версия
   (ближайшие ниже, затем выше) -> более старые -> более новые; только в пределах диапазонов, которые требуют
   другие пакеты; пре-релизы не берутся. Встроенная база (pgserver) и её драйвер ставятся только проверенной
   версии даже в гибком режиме, иначе не откроются существующие данные. Каждое отклонение крупно показано
   в сводке на экране и в журнале.

   Журналы: %LOCALAPPDATA%\DeskMonitor\logs\install-<дата-время>.log (для человека) и .json (для программ и
   службы ИБ): версии Python и pip, адреса индексов, режим, по каждому пакету - что требовалось, что пробовали,
   что нашли, что поставили, откуда и SHA-256. Пишутся и при неудаче. Логины, пароли и токены в них закрыты
   звёздочками (***).
   Поля журнала для сверки с проверенными нами файлами: lock_check (ok - SHA-256 равен проверенному у нас,
   mismatch - не равен, установка остановлена; not_checked - версия не из нашего списка, сверять не с чем;
   not_applicable - наше колесо), lock_sha256 (проверенная у нас сумма, она записана в wheelhouse\mirror.json),
   sha256 (сумма реально полученного файла), source (index - индекс, cache - кэш, bundle - комплект: так
   помечены наши колёса, у них тоже записан SHA-256). Итог: счётчики lock_ok, lock_not_checked,
   lock_mismatch и список пакетов «не сверено с lock».
   Кэш скачанных колёс: %LOCALAPPDATA%\DeskMonitor\cache\mirror-wheels (после сбоя не качается заново; папку
   можно удалить).

   Сбой и повторный запуск. Старое окружение env\ на время установки переименовывается в env.old\. Успех -
   env.old\ удаляется; сбой (или обрыв) - новое env\ удаляется, env.old\ возвращается. Просто запустите
   start.bat ещё раз: он сам вернёт прежнее и начнёт установку заново. Данные не затрагиваются.

   Обновления. «Обновление программы» и заплатки DeskMonitorMirror-patch-....zip берут архив того же вида.
   Сменить вид можно только вручную (см. «ПЕРЕХОД» выше): скачать новый архив, stop.bat, затем распаковать архив в НОВУЮ чистую папку и
   её start.bat. Папку adapter перенесите из старой папки или возьмите архив «с адаптером» (-with-adapter.zip).

   Если что-то не так:
     «<пакет>==<версия>: файл на зеркале отличается от проверенного у нас: ожидался SHA-256 ..., на зеркале ....[ Скачан файл ... (по lock
        ожидался ...).][ На зеркале для этой версии лежит другой файл (...) вместо ...; возможно, зеркало не
        отдаёт хэши в индексе - сообщите ИТ.] Установка остановлена...» (части в скобках бывают не всегда и
        стоят перед словами «Установка остановлена», а не в конце; в журнале статус hash_mismatch) - файл проверенной версии на зеркале не тот, что мы проверяли: возможна
        подмена или зеркало отдаёт другой файл той же версии. Сообщение заканчивается так: «Установка остановлена,
        версия не заменяется другой: это признак подмены файла на зеркале, а не отсутствия пакета. Обратитесь в
        ИБ/ИТ и не запускайте программу, пока причина не выяснена.» Не обходите: отправьте install-....log и
        install-....json в ИБ/ИТ; ИТ должны положить на зеркало файл с ожидаемой суммой, затем start.bat снова.
     «индекс открыт по http:// без шифрования; попросите ИТ перевести его на https://» (предупреждение, установка
        идёт) - попросите ИТ открыть зеркало по https:// и поменять адрес в настройках pip или mirror.ini.
        Проверенные версии защищены хэшами, остальные - нет.
     «не сверено с lock» в журнале и итоге - версия не из нашего списка, подлинность файла проверить нечем.
     «Индекс пакетов недоступен» - проверьте сеть, VPN, прокси и команду pip config list выше, попросите ИТ
        проверить адрес и доступ к зеркалу, запустите start.bat снова.
     «На индексе нет подходящей версии для ...» (в журнале у пакета - «нет на индексе (...)») - нужной версии
        нет на зеркале: отправьте install-....log ИТ, попросите добавить пакет.
     Отказ по pgserver или psycopg - на зеркале нет проверенной версии; её нужно добавить, заменить нельзя.
     Ошибка в mirror.ini - сообщение называет файл; исправьте строку и запустите снова.
