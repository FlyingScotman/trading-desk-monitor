Desk Monitor - С ЧЕГО НАЧАТЬ (коротко; подробнее - INSTALL.txt и app\INSTALL_BACKEND_WINDOWS.md)

0. ЧТО НОВОГО В 0.2.3 (подробно - CHANGELOG в описании релиза на GitHub)
   - Доступ коллегам по сети (по желанию): пользователи с ролями просмотр / трейдер / администратор,
     вход по паролю, HTTPS, журнал действий. По умолчанию всё как раньше - только этот компьютер.
     Как включить - раздел 9 ниже; пользователи - Настройки -> «Пользователи».
   - Новая страница настроек: разделы слева; юрлица, книги и фондирование - формами вместо JSON,
     с проверкой адаптером перед сохранением и историей правок (кто и когда). Книги из позиций,
     которых нет в настройках, - «не настроено» с кнопкой «+ Добавить». Политика фондирования
     в форме - с адаптером 0.3.1.
   - Мониторы: валюта и эмитент - обычные столбцы с сортировкой и фильтром; «Валюта × тип» -
     матрица (валюты по строкам, типы по столбцам); Минфин - отдельный тип и в валюте; плитка
     «ОВП» - таблицей; история позиции показывает, на каком прогоне стоит точка (разрывы, прошлая
     версия - пунктиром, DV01 на 1 бумагу); «Чего нет в данных» - по причинам и что сделать.

   - Загрузка позиций быстрее и полнее; сверка по книгам: desk.bat inbox reconcile.
   - PnL валютных бумаг - по рыночному курсу 19:00 (курс ЦБ показан рядом).

1. РАСПАКОВАТЬ
   - Сначала: правой кнопкой по zip -> Свойства -> галочка «Разблокировать» -> ОК.
   - Распакуйте в C:\DeskMonitor. Не в «Загрузки», не на рабочий стол, не в Program Files:
     в пути не должно быть пробелов и русских букв.

2. ЗАПУСТИТЬ: двойной щелчок по start.bat.
   Первый запуск ставит окружение (1-3 минуты) и открывает в браузере страницу настроек.
   Окно start.bat не закрывайте: пока оно открыто, Desk Monitor работает.

3. ХАБ (страница настроек, http://127.0.0.1:8100/settings.html)
   - адрес хаба и токен. Токен выдаётся на сервере хаба, право (scope) read
     (mdhub tokens create tdm-history -s read --expires-days 365); с правом snapshots истории не будет;
   - кнопка «Проверить связь» - должна ответить без ошибки (видна последняя дата хаба);
   - если в сеть выходят через прокси - поле «Прокси» (например http://proxy:3128).

4. ПАПКИ С ОТЧЁТАМИ: «+ Добавить папку» -> папка, куда приходит утренний отчёт по позициям,
   подпись «Позиции». Папку с PnL тоже можно добавить, но PnL пока не обрабатывается.

5. АДАПТЕР загружается сам из папки adapter этого архива - ничего указывать не нужно.
   - Книги создаются автоматически из отчёта (юрлицо + книга).
   - Позже, для красивых названий и типов книг, в разделе «Файлы настроек адаптера»
     можно заполнить books.json.
   - Имя файла отчёта задаёт patterns.json. По умолчанию ожидается гггг-мм-дд.xlsx
     (например 2026-10-20.xlsx). Если файлы называются иначе - поправьте шаблон там.
   - Знак и валюта NPV/DV01 деривативов: options.json -> report_risk.

6. ПРОВЕРИТЬ
   - На главной (http://127.0.0.1:8100/) в шапке нажмите «Обновить» (или подождите минуту -
     автопилот сам заберёт снапшоты, отчёт и посчитает EOD). Ссылка «Настройки» - там же.
     Мониторы: http://127.0.0.1:8100/concepts/index.html.
   - Что смотреть: дата прогона в шапке мониторов; позиции в C03 «Позиции» (облигации,
     которых нет на хабе, будут «не оценено»).
   - Выбор юрлиц и книг запоминается между прогонами и перезапусками.

7. ГДЕ ДАННЫЕ И КАК ОБНОВЛЯТЬ
   - Данные и настройки: %LOCALAPPDATA%\DeskMonitor (или C:\DeskMonitorData, если в имени
     пользователя русские буквы; start.bat печатает путь). Папка программы их не содержит.
   - Новая версия с GitHub: программа сама замечает её (в шапке страниц появится «Новая
     версия ...»). Настройки -> «Обновление программы» -> «Обновить до ...»: архив скачается
     (сервером или браузером в папку «Загрузки»), контрольная сумма сверится, программа
     перезапустится сама. Если не скачивается - там же «Диагностика связи» покажет, какой
     путь работает и что сказать ИТ. Откат: кнопка «Вернуть ...». Адаптер не меняется.
   - Обновление из браузера: Настройки -> раздел «Обновление программы». Положите zip новой
     версии (полный DeskMonitor-....zip или заплатку DeskMonitor-patch-....zip) в папку
     обновлений (путь задаётся там же, можно сетевую папку) или нажмите «Загрузить zip
     с компьютера», затем «Установить». Окно start.bat не закрывайте: программа сама
     перезапустится (около минуты), страница обновится. Не запустилась новая версия -
     вернётся прежняя, причина будет на странице.
   - Вручную (в первый раз, пока установлена версия без этого раздела, или если страница
     так советует, например при новом Python): stop.bat в старой папке, затем распакуйте
     новую версию в ту же или другую папку и запустите её start.bat.
   - Настройки, токен и данные сохраняются; последний день после обновления пересчитается сам.

8. ЕСЛИ ЧТО-ТО НЕ ТАК
   - Диагностика для агента: Настройки -> раздел «Диагностика» -> «Собрать диагностику»,
     затем «Скачать» или «Скопировать». В файле нет позиций, книг, ISIN, сумм, путей и паролей.
     Из командной строки: desk.bat diagnostics --out diag.json
   - Журналы: %LOCALAPPDATA%\DeskMonitor\logs (serve.log, autopilot.log, update.log).
   - Проверка отчётов без базы (печатает только количества и коды, без данных):
       desk.bat adapter check --dir C:\путь\к\папке\отчётов
   - Проверка хаба:  desk.bat hub-check
   - Ошибка 407 от прокси = прокси требует вход NTLM/Kerberos, так подключиться нельзя.
     Обходной путь - папка ручной загрузки снапшотов (snapshot_drop), см.
     app\INSTALL_BACKEND_WINDOWS.md, раздел «Если что-то не так».
   - Остановить всё: stop.bat.

9. ДОСТУП КОЛЛЕГАМ ПО СЕТИ (по желанию; по умолчанию Desk Monitor открыт только на этом компьютере)
   Коллеги открывают монитор в своём браузере по имени или адресу этого компьютера и входят
   под своими именами и паролями. Пароли хранятся только в виде хэша (Argon2id).
   Все команды - в командной строке (Пуск -> cmd) в папке программы, например:  cd /d C:\DeskMonitor

   Шаг 1. Создать администратора (себя):
       desk.bat user add ivanov --role admin --display-name "Иванов И."
     - user add      - новый пользователь;
     - ivanov        - имя для входа: латиница, цифры, точка, дефис (регистр не важен);
     - --role admin  - роль: viewer (просмотр всех страниц), trader (+ точные сценарии,
                       кнопка «Обновить» автопилота, свои названия бумаг ✎),
                       admin (+ настройки, адаптер, обновления, пользователи);
     - --display-name - как показывать в шапке (необязательно).
     Пароль спросят дважды (символы не отображаются), не короче 8 знаков.
     Другой способ: открыть на этом компьютере http://127.0.0.1:8100/login.html - пока
     администратора нет, там форма «Первый администратор» (с других компьютеров её нет).

   Шаг 2. Завести коллег: Настройки -> «Пользователи» (http://127.0.0.1:8100/settings.html#users,
     или ссылка «Пользователи» в шапке после входа): имя, роль, временный пароль; при первом
     входе коллега задаст свой.
     Или командой:  desk.bat user add petrov --role trader --temporary
     (--temporary - пароль временный, сменить при первом входе).

   Шаг 3. Включить вход и доступ из сети:
       desk.bat lan enable --self-signed
     - lan enable    - включает вход по паролю (настройка auth) и слушает сеть (bind_host 0.0.0.0 -
                       все сетевые адреса этого компьютера; свой адрес: --host 10.1.2.3);
     - --self-signed - HTTPS с сертификатом, созданным здесь (папка tls в данных). Браузер
                       коллеги один раз предупредит «Подключение не защищено»: «Дополнительно» ->
                       «Перейти на сайт». Сертификат от ИТ (корпоративный центр сертификации):
                       --cert C:\путь\desk.crt --key C:\путь\desk.key вместо --self-signed.
                       Без шифрования (не советуем: пароль идёт по сети открытым текстом, на каждой
                       странице жёлтое предупреждение): --plain-http;
     - --port 8100   - другой порт (необязательно);
     - --no-admin-from-network - настройки, адаптер и обновления только с этого компьютера
                       (по умолчанию администратор может и с другого).
     Без администратора команда откажется. Без входа по паролю сервер не станет слушать сеть.

   Шаг 4. Открыть порт в брандмауэре Windows (один раз; нужны права администратора Windows):
     Пуск -> cmd -> правой кнопкой «Запуск от имени администратора», затем
       cd /d C:\DeskMonitor
       desk.bat firewall add
     Она выполняет (то же можно ввести вручную):
       netsh advfirewall firewall add rule name="Desk Monitor (TCP 8100)" dir=in action=allow protocol=TCP localport=8100 profile=domain,private
     - name=...       - название правила (видно в «Брандмауэр Защитника Windows» -> «Дополнительные параметры»);
     - dir=in         - входящие подключения (к этому компьютеру);
     - action=allow   - разрешить;
     - protocol=TCP localport=8100 - только порт Desk Monitor;
     - profile=domain,private - в сети организации и частной сети, не в общественной (кафе, гостиница).
     Только из своей подсети: desk.bat firewall add --remoteip localsubnet. Убрать правило:
     desk.bat firewall remove. Нет прав администратора - попросите ИТ выполнить строку netsh выше.
     Если ИТ закрывает порты на уровне сети - им нужен этот же порт (TCP 8100) к этому компьютеру.

   Шаг 5. Перезапустить: stop.bat, затем start.bat. Окно start.bat покажет «для коллег: https://ИМЯ-ПК:8100/».
     Этот адрес и отправьте коллегам (имя компьютера: Пуск -> «О системе»; адрес: ipconfig).
     Компьютер должен быть включён и окно start.bat открыто, пока коллеги работают
     (запуск службой Windows без входа в систему - в следующих версиях).

   Проверить (Desk Monitor запущен, команда - во втором окне cmd в папке программы):
       desk.bat lan status
     Печатает:
     - sign-in (auth)  - включён ли вход по паролю;
     - listens on      - адрес и порт сервера (0.0.0.0 - все адреса этого компьютера, 127.0.0.1 тоже);
     - HTTPS, certificate - есть ли шифрование, до какой даты сертификат и на какие имена и адреса
                         он выписан; «not in the certificate» - адреса этого компьютера, которых в нём нет
                         (браузер коллеги предупредит; новый сертификат: desk.bat lan enable --self-signed);
     - firewall rule   - есть ли правило «Desk Monitor (TCP 8100)» (смотрит netsh ... show rule,
                         права администратора не нужны);
     - colleagues open - адреса, которые отправить коллегам;
     - self-check      - проверка запущенного сервера с этого же компьютера, без прокси: сначала
                         127.0.0.1, потом каждый сетевой адрес. Для каждого одно из:
         ok (отвечает)            - этот Desk Monitor отвечает на адресе;
         no_response (TCP есть, ответа нет) - соединение установлено, но никто не отвечает:
                                    порт на этом адресе держит другой процесс (старый экземпляр,
                                    другая программа) или соединение перехватывает антивирус;
         other_server             - отвечает другой сервер, не этот Desk Monitor;
         tls_error (ошибка HTTPS) - на адресе сервер без HTTPS или чужой сертификат;
         refused                  - порт на адресе никто не слушает (сервер не запущен или
                                    после lan enable не перезапущен);
         timeout                  - соединение не устанавливается (брандмауэр, VPN, сеть).
       Под каждой неудачной строкой - подсказка, что делать.
     - --no-probe  - без проверки (если сервер не запущен); --timeout 5 - ждать каждый адрес
       5 секунд (по умолчанию 3); --json - то же в JSON. Код выхода 1, если какой-то адрес не ответил.
     Та же проверка идёт сама при каждом запуске: строки «проверка адреса» в окне start.bat и в
     logs\serve.log. И на странице: Настройки -> «Диагностика» -> «Доступ из сети» (адреса для коллег,
     проверка при запуске и кнопка «Проверить сейчас»).
     Проверка с этого же компьютера не проходит брандмауэр Windows: «ok» значит, что сервер отвечает
     на сетевом адресе; если коллеги всё равно не открывают - правило брандмауэра (шаг 4) или прокси
     в их браузере (адрес - в исключения прокси: Свойства браузера -> Подключения -> Настройка сети).

   Если коллеги не открывают, а на этом компьютере https://127.0.0.1:8100 работает:
     1) desk.bat lan status - что показывает self-check для сетевого адреса (см. выше);
     2) netstat -ano | findstr :8100 - ВСЕ строки LISTENING. Нормально - одна строка 0.0.0.0:8100
        (или ваш адрес и 127.0.0.1). Лишняя строка с вашим адресом или чужим PID (последняя колонка;
        имя процесса - Диспетчер задач -> Подробности) - порт держит другой процесс: закройте его
        или возьмите другой порт;
     3) curl.exe -kv --noproxy "*" https://ВАШ-АДРЕС:8100/health/live
        - -k - не проверять сертификат (он самоподписанный); -v - показать каждый шаг;
          --noproxy "*" - мимо прокси. Ответ {"status":"ok"} - сервер отвечает. «Connected», а дальше
          тишина - ответа нет (как no_response). Повторите с https://127.0.0.1:8100/health/live: если и
          там тишина - завис сам сервер, перезапустите его (stop.bat, start.bat) и пришлите logs\serve.log;
     4) другой порт:  desk.bat lan enable --self-signed --port 8443, затем stop.bat и start.bat
        (правило брандмауэра - на новый порт: desk.bat firewall add);
     5) свой адрес вместо 0.0.0.0:  desk.bat lan enable --self-signed --host ВАШ-АДРЕС
        (адрес - ipconfig, «IPv4-адрес»; сервер будет слушать этот адрес и 127.0.0.1; если порт на
        этом адресе занят другим процессом, сервер не запустится и скажет об этом);
     6) без HTTPS, только чтобы понять, не мешает ли HTTPS (антивирус с проверкой HTTPS):
        desk.bat lan enable --plain-http, перезапуск, коллеги открывают http://... ; потом верните
        desk.bat lan enable --self-signed.
   Вернуть «только этот компьютер»: desk.bat lan disable (вход остаётся) или
   desk.bat lan disable --auth-off (и вход выключить), затем перезапуск.
